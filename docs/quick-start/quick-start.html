Quick start

How to put the InScan test app on a phone and connect it to the shop system. About five minutes per phone.

Have these ready

  • An Android phoneAndroid 7 or newer, with Wi-Fi or mobile data. iPhones can't run this file.
  • The app fileinscan-test-96.apk, sent with this guide.
  • One setup code for each phoneSent to you separately. Each code works once, within 24 hours.
  • A PIN for each person4 to 8 digits. Each person gets their own.
  • The shop system addressSent to you separately, with the setup codes. You type it in step 2.
1

Put the app on the phone

First
Open the file on the phone. Tap inscan-test-96.apk in the email, message or folder it arrived in.
Then
Allow the install. The first time, Android asks if that app may install other apps. Tap Settings, switch on Allow from this source, then go back.
Last
Tap Install, then Open. The app is called Country ATV InScan.
Your phone may warn you about the file. That is normal for an app that doesn't come from the Play Store. If it offers to scan the app, let it, then choose to install anyway. The exact words differ from phone to phone.
Had an older InScan on this phone? It stays as a separate app with its own data. Once the new one is connected and working, remove the old one so nobody opens it by mistake.

The first time the app opens it shows this screen. You only do this once per phone.

Skip the small grey line that says "run: inscan-server setup-code". That part is done on our side. Your codes come from us.
Out of codes, or one didn't work? Ask us for a new one. After five wrong codes in a row the shop system stops taking codes from your connection for 15 minutes.

Good to know

No signal? Keep working. The phone shows how many changes are waiting and sends them when it can reach the shop system again.

Signed out? A sign-in lasts 12 hours, and the app locks after 30 minutes of not being used. Enter your PIN and you pick up where you left off.

A newer version? We send a new file. Open it on the phone: it installs over this one and the phone keeps its data.

If something goes wrong

What the phone saysWhat to do
"Can't reach the shop system right now. Check the phone's Wi-Fi or signal." Check the phone has internet. Then check the address: it must start with https:// and match the address we sent you exactly.
"That setup code didn't work. Codes work once and expire after a day." The code was already used, is older than a day, or was mistyped. Ask us for a new one.
"No employees are set up yet." Nobody has been added for your shop yet. Tell us the names and we add them.
The file won't install Make sure it is an Android phone on Android 7 or newer, and that you allowed the install in step 1.
This is a test version. Use it the way you would on a normal day and tell us what is slow, confusing or broken. To reach us, reply to the message this guide came with.
